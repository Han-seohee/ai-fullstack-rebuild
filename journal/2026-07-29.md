# 2026-07-29

오늘은 AI Dev Assistant의 프론트와 백엔드가 실제로 통신하는 구조를 만들었다.

단순히 화면만 만드는 것이 아니라, 앞으로 OpenAI를 붙일 수 있는 기반을 만드는 것이 목표였다.

## Context

어제까지는 UI와 Mock 데이터만 화면에 출력하는 상태였다.

오늘은 Next.js App Router의 API Route를 사용해 프론트엔드와 백엔드가 실제로 통신하도록 구현했다.

또한 사용자가 실제 서비스처럼 사용할 수 있도록 복사 기능, 입력 검증, 에러 처리 등 기본적인 UX도 함께 개선했다.

## Decision

Express를 따로 사용하지 않고 Next.js Route Handler를 서버 역할로 사용하기로 했다.

현재 프로젝트는 MVP 단계이므로 서버와 프론트를 하나의 프로젝트에서 관리하는 것이 가장 단순하고 유지보수하기 쉽다고 판단했다.

또한 OpenAI 연동 전에 Mock API를 먼저 구현하여 프론트와 백엔드의 데이터 계약(JSON 구조)을 먼저 검증하는 방식을 선택했다.

사용자 경험도 함께 고려하여 다음 기능을 추가했다.

- 공백 입력 방지 (`trim()`)
- Loading 상태 표시
- 에러 처리
- 커밋 메시지 / 개발일지 복사 기능
- 복사 완료 피드백 제공

## Outcome

이제 프론트는 Mock 데이터가 아니라 API를 통해 데이터를 받아 화면에 출력한다.

OpenAI만 연결하면 실제 AI 서비스로 확장할 수 있는 구조가 준비되었다.

또한 UI와 데이터 처리 로직을 분리하고, 중복 코드를 함수로 분리하면서 이전보다 코드의 책임이 명확해졌다.

기존에는 프론트엔드 중심으로 API를 사용하는 입장이었다면, 이번에는 Next.js App Router의 Route Handler를 활용해 서버 엔드포인트까지 직접 구성했다. 앞으로 OpenAI 연동도 같은 구조에서 확장할 수 있도록 기반을 마련했다.
