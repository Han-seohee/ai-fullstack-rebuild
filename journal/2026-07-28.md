# 2026-07-28

AI Dev Assistant의 첫 번째 MVP UI를 구현했다.

## Context

프로젝트의 첫 목표는 실제 AI 기능보다 먼저 "사용자가 어떤 흐름으로 사용하는지"를 확인하는 것이었다.

최소한의 화면만으로도 입력 → 생성 → 결과 확인 → 복사까지의 경험을 만들고 싶었다.

또한 이 프로젝트는 단순한 ChatGPT 래퍼가 아니라, 개발자가 실제 커밋과 개발일지를 작성할 때 사용할 수 있는 도구를 목표로 한다.

## Decision

UI는 최대한 단순하게 유지하기로 했다.

- 한국 개발자를 대상으로 하므로 전체 UI를 한국어로 구성했다.
- 결과 영역을 처음부터 보여주어 생성 결과를 예측할 수 있도록 했다.
- 커밋 메시지와 개발일지를 각각 카드로 분리했다.
- 결과를 바로 사용할 수 있도록 복사 버튼을 미리 배치했다.
- 디자인보다 실제 사용 흐름(MVP)에 집중하기로 했다.

## Outcome

입력 → 생성 → 결과 확인이라는 기본 구조가 완성되었다.

아직 AI는 연결되어 있지 않지만, 실제 서비스처럼 사용할 수 있는 형태가 만들어졌다.

UI를 계속 수정하기보다 이제는 OpenAI API를 연결하고 프롬프트를 설계하는 단계로 넘어갈 준비가 되었다.
