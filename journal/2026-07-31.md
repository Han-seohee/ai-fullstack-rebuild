# 2026-07-31

OpenAI API를 실제 서비스에 연결하고, Prompt를 별도 파일로 분리해 관리하는 구조를 만들었다.

## Context

AI Dev Assistant가 Mock 데이터를 반환하는 수준에서 실제 OpenAI 응답을 생성하는 서비스로 발전시키는 작업을 진행했다.

Responses API를 적용하고 Prompt를 독립적으로 관리할 수 있는 구조를 만드는 것을 목표로 했다.

## Decision

Prompt를 route.ts 내부 문자열이 아닌 `prompt.ts`로 분리했다.

Prompt는 애플리케이션의 핵심 로직 중 하나이므로, API 호출 코드와 분리해 관리하는 것이 유지보수와 반복적인 개선(Prompt Engineering)에 적합하다고 판단했다.

또한 AI가 입력되지 않은 내용을 추측하지 않도록 Prompt에 명확한 규칙을 추가했다.

## Outcome

OpenAI Responses API 연동을 완료했다.

Prompt를 별도 모듈로 분리하여 앞으로 Prompt 자체를 지속적으로 개선할 수 있는 구조를 만들었다.

Responses API의 JSON 응답 제약사항을 확인하고 Prompt를 수정하여 정상적으로 동작하도록 해결했다.

AI 결과의 품질은 모델보다 Prompt와 입력 정보의 품질에도 크게 영향을 받는다는 점을 직접 경험했다.

## 🚨 Troubleshooting

### 문제

Responses API 호출 시 500 에러가 발생했다.

```
Response input messages must contain the word 'json'
```

### 원인

`text.format`을 `json_object`로 지정한 상태에서 Prompt에 JSON 응답을 명확하게 요구하지 않아 API 요청이 거부되었다.

### 해결

SYSTEM_PROMPT와 사용자 입력 템플릿을 수정하여 JSON 응답을 명시적으로 요구하도록 변경했다.

### 배운 점

OpenAI API는 단순히 SDK를 호출하는 것만으로 끝나지 않는다.

API가 요구하는 Prompt 규칙과 응답 형식까지 함께 이해해야 안정적으로 사용할 수 있다는 점을 확인했다.
