# 2026-07-30

Mock 기반으로 구현했던 API를 실제 OpenAI API로 교체했다.

## Context

초기에는 프론트와 API 간 데이터 구조를 확인하기 위해 Mock 응답을 사용했다.

기본 UI와 API 흐름이 안정화되어 실제 OpenAI API를 연결하는 작업을 진행했다.

## Decision

기존 프론트의 API 호출 방식은 그대로 유지하고 Route Handler 내부 구현만 OpenAI 호출로 변경했다.

또한 API Key는 `.env.local`에서 관리하고 서버에서만 접근하도록 구성했다.

## Outcome

UI 수정 없이 실제 OpenAI 응답을 받아오는 구조로 변경했다.

프론트와 서버가 같은 `GenerateResult` 타입을 공유하고 있어 OpenAI 연동 후에도 별도의 화면 수정 없이 정상 동작하는 것을 확인했다.
