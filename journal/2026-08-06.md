## 🚨 Troubleshooting

### 문제

History에서 이전 결과를 선택하면 내용은 정상적으로 복원되지만 화면이 그대로여서 변경 여부를 바로 확인하기 어려웠다.

또한 새로고침 시 작업 내용은 유지되지만 Wizard가 첫 단계가 아닌 트러블슈팅 단계부터 복원되는 문제가 있었다.

### 원인

History는 결과 데이터만 복원하고 화면 이동을 처리하지 않았고, Wizard 관련 상태가 localStorage를 통해 함께 복원되고 있었다.

### 해결

History 선택 시 결과 영역으로 자동 스크롤하도록 개선하고, 새로고침 시에는 작업 내용만 유지한 채 Wizard 진행 상태는 초기화하는 방향으로 수정했다.

### 배운 점

기능이 정상적으로 동작하는 것과 사용자가 자연스럽게 인지하는 것은 다른 문제였다. 릴리즈 직전에는 기능 구현보다 사용자 흐름을 점검하는 과정이 중요하다는 것을 다시 확인했다.
