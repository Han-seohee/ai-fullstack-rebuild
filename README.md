# ai-fullstack-rebuild

AI 시대에 풀스택 개발자로 다시 성장하는 과정을 기록하는 저장소입니다.

이 저장소는 튜토리얼을 정리하는 공간이 아니라,
직접 프로젝트를 만들며 고민했던 과정과 시행착오를 기록합니다.

---

## 🎯 Goal

- AI를 개발 워크플로에 자연스럽게 활용하기
- 프론트엔드부터 백엔드, 배포까지 직접 경험하기
- 반복 작업을 자동화하는 개발 습관 만들기
- 취업 가능한 포트폴리오 만들기
