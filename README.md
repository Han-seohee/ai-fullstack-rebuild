## 💡 이 저장소에 남기는 것

공식 문서를 베끼거나 강의 노트를 쌓는 곳이 아니다.  
**왜 이렇게 했는지**, **뭘 시도했다가 바꿨는지** — 코드보다 그 판단 과정이 핵심이다.

| 폴더 | 내용 |
|------|------|
| [`journal/`](journal/) | 날짜별 성장 기록 |
| [`projects/`](projects/) | 직접 만든 것 (`01-`, `02-` …) |

## 📝 Journal

`journal/YYYY-MM-DD.md` — **5~10분**이면 충분하다.

```markdown
## Context    — 뭘 하려 했는지
## Decision   — 왜 이 선택을 했는지
## Outcome    — 유지할 것 / 바꿀 것

## 🚨 Troubleshooting (Optional)

### 문제
### 원인
### 해결
### 배운 점

## Next       — 다음에 할 것
```

Troubleshooting은 매일 쓰는 항목이 아니다. 개발 중 막혔다가 해결한 경험이 있을 때만 Outcome과 Next 사이에 추가하면 된다.

- Day 1 · [2026-07-27](journal/2026-07-27.md)
- Day 2 · [2026-07-28](journal/2026-07-28.md)
- Day 3 · [2026-07-29](journal/2026-07-29.md)
- Day 4 · [2026-07-30](journal/2026-07-30.md)
- Day 5 · [2026-07-31](journal/2026-07-31.md)
- Day 6 · [2026-08-01](journal/2026-08-01.md)
