# ai-fullstack-rebuild

AI 시대에 풀스택 개발자로 다시 성장하는 과정을 Public으로 기록하는 저장소.

튜토리얼 정리가 아니라, **실제로 개발하면서 내린 판단과 시행착오**를 남긴다.

## 🎯 Goal

- AI 활용 능력 — 개발 워크플로에 자연스럽게 녹이기
- 풀스택 개발 — 프론트부터 배포까지 직접 경험하기
- 자동화 — 반복 작업을 줄이는 습관 만들기
- 취업 가능한 포트폴리오 — 코드와 함께 **사고 과정**이 보이게

## 💡 이 저장소에 남기는 것

공식 문서를 베끼거나 강의 노트를 쌓는 곳이 아니다.  
**왜 이렇게 했는지**, **뭘 시도했다가 바꿨는지** — 코드보다 그 판단 과정이 핵심이다.

| 폴더 | 내용 |
|------|------|
| [`journal/`](journal/) | 날짜별 성장 기록 |
| [`projects/`](projects/) | 직접 만든 것 (`01-`, `02-` …) |

## 📝 Journal

`journal/YYYY-MM-DD.md` — **5~10분**이면 충분하다.

```markdown
## Context    — 뭘 하려 했는지
## Decision   — 왜 이 선택을 했는지
## Outcome    — 유지할 것 / 바꿀 것
## Next       — 다음에 할 것
```
